# This repository is intended for learning purposes only.

# Pull the repo to local machine 
```
git clone https://github.com/mouadTaoussi/ai-assistant.git
```

# To build containers in developement mode 
```
docker compose -f compose.dev.yaml build
```

# To run containers in developement mode
```
docker compose -f compose.dev.yaml up
```

# To stop running containers 
```
docker compose compose.dev.yaml down
```

# To build containers in production mode 
```
docker compose -f build
```

# To run containers in production mode
```
docker compose -f up
```

# To stop running containers 
```
docker compose down
```
